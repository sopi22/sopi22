# I'm Jhoana Sophia Munar

IT student. I build small tools, then try to break them to see if they really work.

## Projects

- **[StayGone](https://github.com/sopi22/StayGone)**: PowerShell script that keeps Windows bloatware (Xbox, Clipchamp) removed after updates.
- **[RepoNudge](https://github.com/sopi22/RepoNudge)**: tells you when a GitHub repo needs attention: failing tests, unreleased work, open issues.
- **[joplin-reading-copy](https://github.com/sopi22/joplin-reading-copy)**: shares a Joplin notebook as read-only PDFs through Proton Drive.
- **[polygraph](https://github.com/sopi22/polygraph)**: checks AI model files in a sandbox: does the file do what its label says?
- **[chronobot](https://github.com/sopi22/chronobot)**: Telegram reminder bot that asks when a time is unclear. Runs on Vercel.
- **[caveat-keeper](https://github.com/sopi22/caveat-keeper)**: finds warnings that go missing from AI-written project notes.
- **[phone-tryout](https://github.com/sopi22/phone-tryout)**: tests Android phone behaviour with adb instead of trusting what the phone reports.
